# Proposal

Implementar a renderizacao do contrato validado ChartSpecification no Copilot Web.

A resposta estruturada continua sendo validada pelo Backend; o Frontend apenas escolhe uma representacao visual segura a partir dos campos definidos no contrato, sem executar codigo ou interpretar formatos alternativos.

## Non-goals

- Alterar o contrato JSON Schema ou as ferramentas de Analytics.
- Calcular metricas no Frontend.
- Introduzir uma biblioteca externa de graficos.
